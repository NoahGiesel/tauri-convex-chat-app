## Geo Duel city list

`convex/geoPlaces.ts` is generated by `scripts/geo-places/build.mjs` from GeoNames `cities15000.zip`, `countryInfo.txt` and `alternateNamesV2.zip`, plus the hand-review file `scripts/geo-places/exclude.txt` when it exists. Only the server uses it. The module header records the date and SHA-256 of each source file.

Contains data from GeoNames, <https://www.geonames.org>, licensed under CC BY 4.0, <https://creativecommons.org/licenses/by/4.0/>. The list keeps only some places and fields, rounds the coordinates and picks one name per language.

## Geo Duel photos

`convex/geoPhotos.ts` is generated by the same script from Wikidata (CC0, <https://www.wikidata.org>) and Wikimedia Commons. The photos stay on Wikimedia Commons, each under its own licence (mostly CC BY-SA and CC BY, some public domain); the game shows each photo's author and licence, and links its Commons page after the Round.
